# Code of Conduct

Hiptop adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, for every repository in the `hiptop-ai` organization and every space where the project is represented.

In short: be respectful, assume good intent, welcome newcomers, and keep criticism about the work.

## Reporting

Report unacceptable behavior privately to the maintainers at **[CONDUCT CONTACT EMAIL]**. Every report is reviewed and kept confidential. Maintainers who do not follow the code of conduct may be removed from the project.
