# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub Security Advisories](https://github.com/hiptop-ai/hiptop-ai/security/advisories/new) on the affected repository.

We acknowledge reports within 3 working days and keep you informed until the issue is resolved. We credit reporters in the advisory unless you prefer otherwise.

## Supported versions

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Scope of Hiptop's security features

Hiptop's security assessment runs only against devices in the user's own inventory (Cuttlefish and declared lab devices). Use it only on systems you own or are authorized to test. Hiptop helps produce Cyber Resilience Act artifacts; it does not certify compliance.
