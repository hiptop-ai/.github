<p align="center"><strong>Nothing is done until a test proves it.</strong></p>

Hiptop is an open source, agentic toolkit for building Android, from apps to the AOSP platform. It works with the coding agent you already use and holds one rule: nothing is done until a test ran, passed and is bound to the commit.
